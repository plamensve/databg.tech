Overview REST API MCP Example Status
OVERVIEW

DataBG machine access

DataBG will provide structured access to Bulgarian datasets through programmatic interfaces designed for developers, applications and AI agents.

REST API

Predictable HTTP endpoints

Applications will be able to search and retrieve structured data through standard REST endpoints.

Example request 
GET /v1/doctors/search
?specialty=Cardiology
®ion=Ruse
&limit=10
MCP

Native access for AI agents

DataBG will expose MCP tools so compatible AI agents can discover and query datasets directly.

Planned MCP tool 
search_doctors(
    specialty="Cardiology",
    region="Ruse",
    limit=10
)
RESPONSE

Structured JSON

Example response 
{
  "results": [
    {
      "uin": "1900000001",
      "name": "Doctor Name",
      "specialty": "Cardiology",
      "workplace": "Medical Center",
      "region": "Ruse"
    }
  ]
}
STATUS

API & MCP are coming soon

The current DataBG MVP focuses on building and validating the underlying datasets. API and MCP access will follow.
