OVERVIEW

DataBG machine access

DataBG is an agent-oriented data and tools platform. Resources can represent structured datasets, web intelligence operations, domain utilities and other machine-accessible services. The platform is designed to work globally rather than being limited to Bulgarian data.

DISCOVERY

Machine-readable catalog

Agents can discover the platform, datasets, tools, endpoints and payment configuration without relying on a human-oriented interface.

Discovery
GET https://api.databg.tech/.well-known/databg.json

GET https://api.databg.tech/.well-known/x402

GET https://api.databg.tech/openapi.json
REST API

Predictable HTTP endpoints

DataBG resources use standard HTTP endpoints and return structured JSON. Current resources include datasets, web intelligence, DNS and TLS utilities, IP geolocation, domain lookup and blockchain intelligence.

Tool examples
GET https://api.databg.tech/v1/tools/ip/geolocation
    ?ip=8.8.8.8

GET https://api.databg.tech/v1/tools/domain/lookup
    ?domain=google.com

GET https://api.databg.tech/v1/tools/dns
    ?domain=example.com
    &type=A
MACHINE PAYMENTS

x402 payment flow

Paid resources can return HTTP 402 Payment Required with machine-readable payment requirements. A compatible client can settle the request in USDC on Base Mainnet and retry.

x402
Request
  ↓
402 Payment Required
  ↓
USDC payment on Base Mainnet
  ↓
Request settlement
  ↓
Structured JSON response
