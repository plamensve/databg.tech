ABOUT DATABG

Bulgarian information.
Built for the AI era.

DataBG is a data infrastructure project focused on transforming fragmented Bulgarian information into structured, machine-readable datasets.

THE PROBLEM

Useful data exists.
Accessing it is difficult.

Valuable Bulgarian information is distributed across many websites, public registers and different formats.

Applications and AI systems often need to discover, scrape, clean and normalize this information before it becomes useful.

DataBG aims to provide a structured layer between those data sources and the systems that need them.

THE PLATFORM

From fragmented sources
to structured data.

01

Collect

Gather information from relevant Bulgarian data sources.

02

Normalize

Clean and transform fragmented records into consistent structures.

03

Connect

Make structured data accessible to applications and AI agents.

THE VISION

A data layer
for Bulgaria.

DataBG is not designed around a single dataset.

The goal is to progressively build a collection of structured Bulgarian datasets behind a consistent API and MCP infrastructure.

The Bulgarian Doctors dataset is the first step.
